## II. 建立控件与寄存器的对应关系

### 1. 在sql文件中添加控件ID与combined_register的tuple

找到控件对应页面的.sql文件（如AEC界面，对应sql文件为`insert_aec.sql`），按照表ui_info以及ui_info_regmodule（详情见文档数据库设计.md）的内容插入tuple。

### 2. 代码中控件与combined_register的映射

控件与combined_register的映射依靠变量`combinedRegisterMap`实现。

```c++
QMap<QString,std::vector<CombinedRegister>> combinedRegisterMap;
```

其中key为控件的label值（部分控件可能不一样，对于RGB/IR帧分开调的寄存器，需要去除名字中的"*"号，并在label后增加"`_RGB_AB`/`_IR_AB`"，且仅在IR_RGB_MODE_REG_ADDR值为1时生效）。

### 3. 将寄存器记录至代码

可通过调用函数`recordCombineRegbyUIifo`来实现。

```C++
void QTabWndComm::recordCombineRegbyUIifo(QString moudle_name, QString uiname, std::shared_ptr<int> cameraId);
```

参数列表：

|    参数     |         对应的DB表 : 列         |
| :---------: | :-----------------------------: |
| moudle_name | combined_register : module_name |
|   uiname    |     ui_info : control_name      |
|  cameraId   |       camera : camera_id        |

此操作可以将控件对应的`combined_register`写入变量`combinedRegisterMap`中。部分页面可能有较为特殊的情况（不同module的控件名称相同），此时可以重写/重载该函数，比如将key值改为"子页面_控件名称"的形式。

### 4. 记录寄存器对应的子tab

可通过**实现**并调用函数`combinedRegisterSubPageRecording`来实现。部分需要RGB/IR帧分开调的寄存器控件需要**实现**并调用`getCombinedRegister`函数。

一般页面的`combinedRegisterSubPageRecording`函数写法如下：

```c++
std::vector<CombinedRegister> combinedRegisterSubPageRecording(QString strModuleName, QString strUiName, std::shared_ptr<int> ptrCamera, QString strSubPage) 
{
    std::vector<UiInfo> uiInfo;
    // qDebug() << strModuleName << ", " << strUiName;
    uiInfo= DatabaseOrm::getUiInfoByModuleNameAndControlName(moduleName, strUiName.toStdString());
    std::vector<CombinedRegister> combinevector;
    for (auto i : uiInfo) {
        CombinedRegister combineReg
            = DatabaseOrm::getCombinedRegisterByModuleNameAndCameraIdAndCombinedName(
                strModuleName.toStdString(), ptrCamera, *(i.combinedName));
        combinevector.push_back(combineReg);
    }

    for (auto reg : combinevector)
    {
        auto reBitInfo = DatabaseOrm::getRegisterBitInfoByCombinedRegister(reg);
        for (int i = 0; i < reBitInfo.size(); i++)
        {
            regAddrModule.insert(reBitInfo[i].registerAddr);
        }
        std::vector<uint32_t>().swap(registerMoudle);
        for (auto iter : regAddrModule)
        {
            registerMoudle.emplace_back(iter);
        }
        // qDebug() << reg.combinedName.c_str() << "," << strSubPage;
        setRegisterSubPage(reg, strSubPage);
    }

    return combinevector;
}
```

`getCombinedRegister`函数写法如下：

```c++
std::vector<CombinedRegister> getCombinedRegister(QString strModuleName, QString strUiName, std::shared_ptr<int> ptrCamera)
{
    std::vector<UiInfo> uiInfo;
    // qDebug() << strModuleName << ", " << strUiName;
    uiInfo= DatabaseOrm::getUiInfoByModuleNameAndControlName(moduleName, strUiName.toStdString());
    std::vector<CombinedRegister> combinevector;
    for (auto i : uiInfo) {
        CombinedRegister combineReg
            = DatabaseOrm::getCombinedRegisterByModuleNameAndCameraIdAndCombinedName(
                strModuleName.toStdString(), ptrCamera, *(i.combinedName));
        combinevector.push_back(combineReg);
    }
    return combinevector;
}
```

对于特殊情况可能需要特殊处理（比如AEC界面，可参照代码的qaectab.cpp）。

如果控件的寄存器拥有分开调RGB/IR的寄存器，则需要调用`getCombinedRegister`函数获取RGB/IR对应的寄存器，再调用`setRegisterTypeMap`函数。

```c++
void QTabWndComm::setRegisterTypeMap(std::vector<CombinedRegister> regVector, std::vector<CombinedRegister> regVectorRgb, std::vector<CombinedRegister> regVectorIr);
```

可参考qawbtab.cpp的实例进行实现。

## III. 页面下方表格的寄存器信息显示

鼠标点击到控件的label时，需要在下方表格显示寄存器的信息。

### 实现方法：使用connect槽函数连接控件与recvEdit函数

```c++
connect(edit,&QLabelEditGroup::releaseLabel,this,[=](){recvEdit(edit->Label());});
connect(box,&QLabelCheckBox::release,this,[=](){recvEdit(box->Label());});
```

部分需要RGB/IR帧分开调的情况，可以写一个新的函数来实现。

比如`recvEditTarget`的实现，用于应对RGB/IR帧分开调的情况，核心逻辑先试用`clearCurrentRigester`清楚表格中的寄存器，再使用数据库相关函数（详情见文档数据库设计.md）拿到combined_register，之后再调用`updateRegisterTable`函数将寄存器逐个插入表格中：

```c++
void QAECTab::recvEditTarget(QString str, QString strModule) 
{ 
    clearCurrentRigester();

    int valTemp = 0;
    QUsbCommunication::getInstance().readBurst(IR_RGB_MODE_REG_ADDR, (unsigned char*)(&valTemp), ADDRESS_LENGTH, VALUE_LENGTH);

    std::vector<CombinedRegister> re;
    std::string strSuffix = strRgbIrMode == "RGB" ? "RGB_AB" : "IR_AB";
    if (valTemp == 0x01)
    {
        re = combinedRegisterMap.value(strModule + "_" + str + " " + strSuffix.c_str());
    }
    else 
    {
        re = combinedRegisterMap.value(strModule + "_" + str);
    }
    
    updateRegisterTable(re);
}
```

## IV. 更新UI界面信息

一般需要在使用registerTable下方的slider/checkbox/edit控件，或者点击read按钮时触发。一般界面会用`UpdateUIValue`函数。

```c++
template <typename T>
void updateUIValue(T& vector,const QString &extraname="");
```

该函数会将变量`vector`中包括的控件中的值更新到界面上。对于不同界面可以采用不同的实现方法，例如imgfmt界面的情况：

```c++
template <typename T>
void updateUIValue(T& vector,const QString &extraname="")
{
    for(auto item:vector){
        uint32_t value=0;
        auto reg=combinedRegisterMap.value(item->Label()+extraname);
        for(int i=0;i<reg.size();i++){
            readCombinedRegisterValue(reg.at(i), value);
            if (item->Label() == "Width" || item->Label() == "Height")
				item->setValue(QString("%1").arg(value));
			else
                item->setValue(QString("0x%1").arg(QString::number(value,16).toUpper().rightJustified(VALUE_HEX_INFO,'0')));
        }
    }
}
```

核心逻辑是获取每个控件的CombinedRegister的Value，再将value显示到对应控件上。
